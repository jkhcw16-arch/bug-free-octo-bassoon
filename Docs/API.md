Rotational Prime Ontology — API Documentation
Overview
The Rotational Prime Ontology (RPO) API provides programmatic access to the ontology’s deterministic decision engine. It exposes endpoints for:
Prime‑indexed semantic encoding
Rotational operator transformation
Paired temporal memory updates
Risk vector computation
Protection projection
Full decision evaluation
The API is designed for government, enterprise, and research environments requiring interpretable, auditable, deterministic decision outputs.
